# Erste Schritte

Diese Anleitung hilft Ihnen, mit dem hsamanafahrzeug Projekt zu beginnen.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie folgendes installiert haben:
- Git
- Einen Texteditor oder IDE Ihrer Wahl

## Installation

### 1. Repository klonen

```bash
git clone https://github.com/hsersar/hsamanafahrzeug.git
cd hsamanafahrzeug
```

### 2. Projekt erkunden

Nach dem Klonen des Repositories können Sie die Projektstruktur erkunden:

```bash
# Alle Dateien anzeigen
ls -la

# Wiki-Dokumentation lesen
cd wiki
cat Home.md
```

## Grundlegende Verwendung

### Projektdokumentation lesen

Alle Dokumentation finden Sie im `wiki/` Verzeichnis:
- `Home.md` - Hauptseite des Wikis
- `Project-Overview.md` - Detaillierte Projektübersicht
- `Getting-Started.md` - Diese Datei
- `Contributing.md` - Beitragsrichtlinien

### Navigation

Die Wiki-Seiten sind miteinander verlinkt. Beginnen Sie mit `Home.md` für einen Überblick über alle verfügbaren Ressourcen.

## Nächste Schritte

1. **Dokumentation lesen**: Machen Sie sich mit der [Projektübersicht](Project-Overview.md) vertraut
2. **Zum Projekt beitragen**: Lesen Sie die [Beitragsrichtlinien](Contributing.md)
3. **FAQ konsultieren**: Schauen Sie in die [FAQ](FAQ.md) für häufige Fragen

## Hilfe erhalten

Wenn Sie auf Probleme stoßen:
1. Überprüfen Sie die [FAQ](FAQ.md)
2. Suchen Sie in den [GitHub Issues](https://github.com/hsersar/hsamanafahrzeug/issues)
3. Erstellen Sie ein neues Issue, wenn Ihr Problem noch nicht behandelt wurde
